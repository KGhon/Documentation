[Title]
Project Setup Helpers

[Category]
Reaper Scripts

[Overview]
A collection of helper tools to automate project setup for different uses.

[Dependencies]
<li>Reaper v7.76+</li>
<li>The GUIToolkit_Kevin.lua file must be in the same location as any Reascript that wants to use it.</li>

[GenerateTracksFromCSV]
Batch generate tracks by reading from a CSV file. The tracks will be named after each CSV entry.

[GenerateRegions]
Batch generate regions for selected folder tracks. The regions will be named after each selected track. The region start and end points are automatically determined by the earliest and latest media item that belongs to a child track of each selected folder track.

[GenerateMarkersFromCSV]
This helper was primarily created to work alongside DaVinci Resolve to transfer accurate time synchs markers into Reaper. DaVinci Resolves provides an "Export Edit Index" option that will export all marker data into a CSV. This CSV can then be used with this helper to transfer those markers to Reaper. Timecodes are read using the format HH:MM:SS:Frames (DaVinci Resolve's CSV uses this format).

[GenerateVOTracksFromCSV]
Batch generate tracks by reading from a CSV file. The tracks will be named after each CSV entry.

[Affix]
Modify selected track names by applying prefix or suffix.

[RemoveAffix]
Modify selected track names by removing the prefix or suffix if it exists.

[VoiceoverFileSplittingTip]
When splitting a combined voiceover file into individual voice line files, use 'Generate Tracks From CSV' to create a unique track named after each of the file names you've pulled from your documentation spreadsheet. Use 'Prefix/Suffix Selected Track Names' to add a prefix or suffix if you want to differentiate the names of the files you're about to render (ie. 'raw_'). Move each clipped voice line onto its respective track. When rendering, set 'Selected media items' as the source. Then use the '$track' wildcard for the file name. Render.

If you are importing to do further processing on the individual voice line files, Reaper will automatically name tracks after the file name. If you added a prefix or suffix, use 'Remove Prefix/Suffix From Selected Track Names'. You can then use 'Generate Regions' from the Sound Design section get create regions for batch rendering processed voice lines.
