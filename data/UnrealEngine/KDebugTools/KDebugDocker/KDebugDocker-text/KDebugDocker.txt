[Title]
UKDebugDocker

[Definitions]
<b>Type:</b> Class
<b>Inherits:</b> UUserWidget
<b>Category:</b> Unreal Engine > KDebugTools

[Overview]
A KDebugDocker is a premade class made to present menus in the KDebug system to users at runtime. It is also able to create popout windows for separating debug menus from the game window. A default DebugDocker already exists, but the class is available for creating your own version of the widget if desired. Apply any custom DebugDocker in 

<i>Project Settings > Plugins > KDebug Tools Settings > Debug Docker</i>
